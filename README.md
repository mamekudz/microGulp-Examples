# microGulp-Examples

Öffentliche Übersicht eigenständiger µGulp™-Beispielprojekte. Jedes Beispiel hat sein eigenes GitHub-Repository; dieses Hauptrepository bindet die geprüften Quellstände als Git-Submodule ein.

## Alle Beispiele laden

```sh
git clone --recurse-submodules https://github.com/mamekudz/microGulp-Examples.git
cd microGulp-Examples
```

Bei einem vorhandenen Checkout: `git submodule update --init --recursive`.
